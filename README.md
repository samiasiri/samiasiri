## How I Build

**Reliability over demos**  
A system should survive failures, retries, malformed inputs, and real operating conditions — not only the ideal path.

**Clear agent boundaries**  
AI systems need explicit permissions, escalation rules, validation, and deterministic controls around critical behavior.

**Explainability over black boxes**  
Important outputs should make their reasoning, source data, or decision path understandable whenever possible.

**Human maintainability**  
Code, workflows, and system rules should remain understandable and maintainable after the first version ships.

**Test before trust**  
Important behavior should be observable, reproducible, and testable before automation is allowed to run unattended.
